# Cli expense tracker

This is a beginner project that i created in C++ after following a course on udemy. 


## Mini PRD
Build a terminal application that lets a user record small daily expenses and review them.

### Requirements
The application must:\
    - show a text-based menu.
    - let the user add an expense with:
        - Amount
        - Category
        - Short description
    - List all recorded expenses.
    - Calculate the total amount spent.
    - Shows totals by category.
    - Validate invalid input such as negative amounts or unsupported menu choices.
    - Keep running until the user chooses to exit.

### Constraints
    - Start with in-memory data only.
    - Use a simple struct/class to represent an expense
    - Do not use a database.
    - Keep the program split into small functions instead of placing everything in main().

### Stretch Features
    - Filter by category.
    - Show the largest expense.
    - Add a monthly budget and warn when the budget is exceeded.

### Learning Goal
You should finish this project understanding:
    - Variables, typees, operators, and conditionals.
    - if, switch, and loops.
    - Functions and parameters.
    - struct and basic objects.
    - std::struct and std::vector.
    - Input validation.
    - Basic program decomposition.
